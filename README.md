### Dependencies

- uv (`uv tool` for basedpyright and ruff)
- npm/node
- rust and rust_analyzer (requires additional install)
- go
- tree-sitter-cli (requires cargo)
- jdk 21
- xclip is required to sync between clipboards in X11
